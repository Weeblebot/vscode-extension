# Changelog

## 1.0.0

The first release from the open source repository.

- Signing in through the browser shows your username.
- A new deployment starts with a script that uses the `discord` and `weeble` globals, like the docs.
- The deployment picker shows each deployment's live revision.
- Deploying records the extension's version with the revision.
- Package request reports no longer show user IDs.
